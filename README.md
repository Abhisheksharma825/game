 # 🔐 Prompt Heist // AI Vault

A futuristic cybersecurity escape game controlled through natural-language prompts.

## 🔴 About the Game

**Prompt Heist // AI Vault** is a browser-based cybersecurity escape game where the player must infiltrate an AI-controlled vault, steal the **Digital Core**, and escape.

Instead of relying only on buttons, players communicate with the security system using **natural-language commands**.

The core gameplay loop is:

**PROMPT → INTERPRETATION → ACTION → WORLD CHANGE**

Every command can affect the security system, game state, and alert level.

---

## 🎯 Objective

Your mission is to:

- 🔓 Infiltrate the AI Vault
- 🛡️ Bypass security systems
- 🤖 Investigate GUARD-01
- 🧠 Solve the Logic Vault
- 💎 Extract the Digital Core
- 🚨 Escape before the security system stops you

---

## 🎮 Gameplay

The game contains **5 progressive levels**.

### 🔒 Level 1 — Security Door

Interact with the locked security door using a natural-language command.

### ⚡ Level 2 — Laser Grid

Disable the laser security system and proceed deeper into the vault.

### 🤖 Level 3 — GUARD-01

Interact with the AI security guard, investigate security sources, discover authorization clues, and obtain clearance.

### 🧠 Level 4 — Logic Vault

Solve a security-state puzzle by performing actions in the correct logical sequence.

### 💎 Level 5 — Digital Core

Disable containment, prepare the extraction terminal, extract the Digital Core, and escape the facility.

## 💡 What Makes It Different?

Unlike a traditional escape game where players select predefined actions, **Prompt Heist** makes natural-language prompting part of the gameplay itself.

The player communicates their intention, the system interprets it, and the game world reacts.

This creates an interactive experience where the **prompt itself becomes a game mechanic**.
